Put Golden Blurgs GIFs (or short .mp4 / .webm clips) in this folder.

Then point an award at it in js/awards.js, for example:
  gif: "images/awards/the-raid.gif"

Keep GIFs small (under ~5 MB each) so the page loads quickly.
For longer scenes, use a YouTube link instead:
  youtube: "https://www.youtube.com/watch?v=XXXXXXXXXXX"
